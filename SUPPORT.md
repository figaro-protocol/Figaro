# Support

Figaro is a protocol project developed in the open. This file says where to
look and how to ask.

## Before asking

- **`README.md`** — what the repository contains and how it is laid out.
- **`docs/`** — the canonical documentation. Start at `docs/README.md`
  (the doc map + ownership map + reading path).
- **`CONTRIBUTING.md`** — local setup, the test commands, repository conventions.
- **`docs/DESIGN_DECISIONS.md`** — read this before reporting anything that
  looks like a kernel bug; the deliberate patterns are catalogued there.

## Asking

- **A bug** — open an issue with the bug-report template.
- **A protocol or design question** — open a GitHub discussion, or a regular
  issue if discussions are not enabled.
- **A security vulnerability** — do not open an issue. Follow `SECURITY.md`.

## What this is not

There is no paid support, no SLA, and no guaranteed response time. Figaro is
pre-deployment; questions are answered on a best-effort basis.
