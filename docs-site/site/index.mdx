Every trade is a contract. Figaro completes it: the buyer bonds twice the payment; each seller bonds twice the cumulative value through its order; each bond is its party's own deterrent; only the buyer resolves, and resolution pays every seller and refunds every bond at once. The protocol is the rules, which anyone may implement and anyone may build on.

This site holds the documents a builder needs to build on those rules. Every page is one file from the [repository](https://github.com/figaro-protocol/Figaro), rendered here at build time and named at the top of the page as its source; the repository is the only place it is written. The protocol as presented to the public is at [figaroprotocol.com](https://figaroprotocol.com).
