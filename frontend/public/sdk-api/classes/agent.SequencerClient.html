    submitUsageClaim

    • submitUsageClaim(claim: SequencerUsageClaim): Promise<{ pending: number }>

      Submit an RPGF usage claim for an order the BATCH path has settled.

      Its own endpoint, not /submit, because a claim is not a kernel operation: it changes no kernel state and the guest applies it against the batch's POST-state, so a claim for an order the same batch resolves is still credited by that batch.

      Build claims with buildUsageClaims — never hand-roll one, and never include a clause or assembly the counter excludes: applyBatchAccrual reverts on it and takes the whole batch, every other party's settlement included.

      Parameters

      • claim: SequencerUsageClaim

      Returns Promise<{ pending: number }>
