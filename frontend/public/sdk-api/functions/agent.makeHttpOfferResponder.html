    Function makeHttpOfferResponder

    • makeHttpOfferResponder(
          handler: OfferHandler,
      ): (requestBody: string) => Promise<HttpOfferResponse>

      Turn a seller's OfferHandler into a framework-agnostic HTTP responder. Any server passes the raw request body; this deserializes, runs the handler, and maps the result to the status contract HttpChannel expects:

      • malformed envelope → 400;
      • handler THREW (tampered/forged offer — the anti-tamper gate) → 422;
      • handler returned null (policy declined a clean offer) → 204;
      • handler returned a signed envelope → 200. A tampered offer is a 422, never a silent 204 — the buyer must see the difference between "declined" and "rejected as forged".
