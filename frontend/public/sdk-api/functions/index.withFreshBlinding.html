    Function withFreshBlinding

    • withFreshBlinding(
          fields: readonly FieldSpec[],
          values: Record<string, unknown>,
          own?: Readonly<Record<string, unknown>>,
      ): Record<string, unknown>

      Fill the blinding field of one set of fields (a clause's top-level fields, or one stages[N]) with a fresh value (freshBlindingHex), kept apart by where a value came from, never by the value itself.

      Without own, every value of values is the filling party's own (a witness it collects, a set it builds from nothing): a value present is kept, and an absent one is drawn.

      With own, values was folded from other sources too (a design's clause data, a catalog, a profile), and own is the filling party's own data for this set: the value own carries is kept, and any other is replaced by a fresh draw, so a value a design, a catalog or a profile published never stands in for the party's draw.

      A set that declares no blinding field gains nothing. The code that collects a party's data calls it once, before the data is hashed; a builder and a hash function never do, so every rebuild of the same data reproduces the same fingerprint.
