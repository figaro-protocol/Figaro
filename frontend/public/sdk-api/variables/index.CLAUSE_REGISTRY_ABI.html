    @figaro-protocol/sdk — Agent SDK for Figaro Protocol

    Standalone TypeScript SDK for reading, analyzing, and proposing Figaro transactions. Works with any ECDSA signing key — human wallets or autonomous agent keys. The kernel verifies parties by ECDSA recovery alone, so buyer and seller are always externally-owned accounts; contract wallets (Safe, ERC-1271) cannot hold the role directly.

    Example

    import { fetchCoreEvents, reconstruct, buildCommitment, calculateBonds } from "@figaro-protocol/sdk";

    // 1. Fetch events
    const events = await fetchCoreEvents(client, addresses, 0n);

    // 2. Reconstruct state
    const processes = reconstruct(events);

    // 3. Calculate bonds
    const bonds = calculateBonds(cumulativeValue, payment);

    // 4. Build commitment
    const { typedData } = buildCommitment({ ... }, domain);
