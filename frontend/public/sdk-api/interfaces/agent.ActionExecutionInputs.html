    Interface ActionExecutionInputs

    Extra inputs an action needs at execution time that the (pure) proposer cannot produce. The SDK executes GIVEN these; it never fabricates a signature.

    attest-as-seller / attest-as-buyer: the merkle-bound payload the agent builds from its hydrated agreement (proof + content + section bytes).

    Type Declaration

    • clauseId: `0x${string}`

      The computeClauseKey(clause, version) bytes32 HASH — NOT the raw clause name buildSectionInclusionProof takes as its clauseKey.

    • contentRef: `0x${string}`

      The content FINGERPRINT — keccak256(content) (content lives off-chain), or sectionHash to re-assert. Never the preimage.

    • proof: readonly `0x${string}`[]
    • Optionalrole?: Commitment

      seller-attest only: distinct role commitment for cross-order attestation; omit for same-order (role = target).

    • sectionHash: `0x${string}`

      The section FINGERPRINT — sectionDataHash(section) (keccak256 of the committed bytes), never the preimage.

    • stage: number
    • target: Commitment
